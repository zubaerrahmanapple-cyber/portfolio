# MD JUBAER Portfolio — Phase 1 (public frontend)

1. Install Node.js LTS from nodejs.org
2. Open this folder in VS Code, then open the terminal (Ctrl + `)
3. `npm install`
4. `npm run dev`  → open the http://localhost:5173 link

All content lives in `src/data/portfolio.js`. Edit your links, photo, CV, projects there.
Empty links automatically show disabled buttons (no broken links).
